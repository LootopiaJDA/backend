1. STOCKAGE DES MOTS DE PASSE - DANGEREUX ⚠️⚠️⚠️
   
   ❌ ACTUELLEMENT: src/services/crypto.service.ts utilise AES-256-CTR
   ```typescript
   export async function encryptText(plainText: string): Promise<string> {
     const key = await getKey();
     const iv = randomBytes(16);
     const cipher = createCipheriv('aes-256-ctr', key, iv);  // ❌ SYMÉTRIQUE
   }
   ```
   
   PROBLÈMES:
   - Chiffrement symétrique = RÉVERSIBLE
   - Si la clé secrète fuit → TOUS les mots de passe exposés
   - Pas de salt différent par mot de passe
   - Clé dérivée de variable d'environnement peu sûre
   
   IMPACT: 🔴 CRITIQUE
   - Toute la base utilisateurs compromise
   - Pas de protection contre les attaques de brute force
   
   ✅ SOLUTION (IMMÉDIATE):
   ```bash
   npm install bcrypt @types/bcrypt
   ```
   
   ```typescript
   // src/services/password.service.ts
   import * as bcrypt from 'bcrypt';
   
   @Injectable()
   export class PasswordService {
     async hashPassword(plainText: string): Promise<string> {
       return bcrypt.hash(plainText, 12);  // Cost factor 12
     }
     
     async verifyPassword(plainText: string, hash: string): Promise<boolean> {
       return bcrypt.compare(plainText, hash);
     }
   }
   ```
   
   Puis:
   - Migrer TOUS les mots de passe existants vers bcrypt
   - Forcer changement de password au login pour les anciens comptes

6. STRING COMPARISON VULNÉRABLE AUX TIMING ATTACKS
   
   ❌ src/services/auth.service.ts lignes 29-30:
   ```typescript
   const decryptedPassword = await decryptText(user.password);
   if (decryptedPassword !== data.password) {  // ❌ String comparison
     throw new UnauthorizedException();
   }
   ```
   
   PROBLÈMES:
   - Comparaison `!==` plus rapide si premiers caractères correspondent
   - Attaquant peut deviner mot de passe caractère par caractère
   - Mesurer le temps de réponse pour déterminer le bon caractère
   
   IMPACT: 🟠 MOYEN
   
   ✅ SOLUTION:
   ```typescript
   import { timingSafeEqual } from 'crypto';
   
   async verifyPassword(plainText: string, encrypted: string): Promise<boolean> {
     const decrypted = await decryptText(encrypted);
     
     try {
       timingSafeEqual(
         Buffer.from(decrypted),
         Buffer.from(plainText)
       );
       return true;
     } catch {
       return false;
     }
   }
   ```

2. PAS DE PAGINATION
   
   ❌ src/services/chasse.service.ts:
   ```typescript

     return this.prisma.chasse.findMany({ where: { etat: "ACTIVE" } })
     // ❌ Retourne TOUTES les chasses!
   }
   ```

   ❌ src/services/etape.service.ts:
   ```typescript

   }
   ```
   
   Risques:
   - 10,000 chasses = 10MB+ JSON
   - Explosion mémoire serveur
   - Premier load très lent
   - Pas d'option tri/filtrage
   
   ✅ Solution:
   ```typescript
   async getAllChasse(
     page: number = 1,
     limit: number = 20,
     sortBy: 'created_at' | 'name' = 'created_at'
   ) {
     const skip = (page - 1) * limit;
     
     const [data, total] = await Promise.all([
       this.prisma.chasse.findMany({
         skip, take: limit,
         orderBy: { [sortBy]: 'desc' },
         select: {
           id_chasse: true,
           name: true,
           localisation: true,
           image: true,
           etat: true,
           _count: { select: { etape: true } }
         }
       }),
       this.prisma.chasse.count({ where: { etat: "ACTIVE" } })
     ]);
     
     return {
       data,
       total,
       pages: Math.ceil(total / limit),

     };
   }
   ```

   ```bash

   ```
   
   ```typescript
   @Get()
   async getAllChasse(page = 1) {
     const cacheKey = `chasse:list:${page}`;
     
     let result = await this.cache.get<ChassePaginated>(cacheKey);
     
     if (!result) {
       result = await this.prisma.chasse.findMany({...});
       await this.cache.set(cacheKey, result, 300000);  // 5 min cache
     }
     
     return result;
   }
   ```
